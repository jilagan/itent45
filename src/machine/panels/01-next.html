How a language model writes: predicting the next word

When you type a message on your phone, the keyboard suggests the next word. It has not understood your message. It has learned which words usually follow the ones you typed. A language model is a program trained on huge amounts of text, and it works on the same idea at a much larger scale. Every answer it gives comes from one repeated step. It reads all the text so far, which is called the context. It works out a probability for every word that could come next, where a probability is a number from 0 to 1 that says how likely that word is. It picks one word, and then it repeats the step. There is no plan, no draft, and no separate step that checks whether the sentence is true.

Think first. Finish this sentence and write down your answer: "The capital of France is". Then ask yourself whether you looked a fact up, or whether the words led you to the ending.
After students answer, point out that almost everyone said the same word instantly. The model does the same thing with numbers attached. The distinction between recalling a fact and continuing a pattern comes up again in the code example below.

This section shows one step. The model gives a probability for every candidate word, and then one word is picked. The list of probabilities for all candidates is called a probability distribution. The first two prompts are sentences. The third is the start of a line of Python code that looks up a user in a database. The model has to choose between two database commands, get and filter.

Temperature setting
Temperature controls how far down the list the model is willing to reach. At 0 it takes the top word every time. At 1 it picks at random, in proportion to the percentages shown. Picking at random in proportion to the percentages is called sampling.

Press "Do it ten times" at temperature 0, then again at 1.2, and compare the two tallies.
Temperature 0 gives the most likely word, which can still be wrong At temperature 0 the model takes the most likely word each time. If that top word is wrong, you get the same wrong answer every time you ask, worded the same way and equally confident. That is harder to spot than an answer that changes from run to run.

A full answer is the same step repeated. The model takes the word it picked, adds it to the end of the prompt, and asks the same question again. A long answer of perhaps eight hundred words is built this way, one chosen word at a time. A model that works this way is called generative, because it produces new text.

What changes in the loop
After the first word, the model reads its own output as part of the prompt. By the time the next word is chosen, the words it wrote are treated the same way as the words you wrote.

The model never goes back. Once a word is added, every later word is chosen with that word already in place. The model does not reconsider a sentence it has started.
Why one early error can run through a whole answer If the model picks a slightly wrong word early, every word after it is chosen to fit that word. The result reads smoothly to the end, because each word is chosen to be a likely continuation of the text before it.
Generative models and classifiers In the panel "Training data and test data", the boundary answered a closed question: which side is this student on? The answer was one choice from a set that existed before the model ran, and nothing new was made. A program that sorts inputs into fixed categories like this is called a classifier.

The model in this panel answers an open question. The set of possible answers is every sequence of words there is. The word generative refers to this open set. A generative model's output can be fluent, new and wrong at the same time. A classifier can only be wrong in the ways its fixed set of answers allows.
Image generators work differently Image generators mostly start from random dots, called noise, and remove the noise in steps until a picture is left. That process is different from predicting words, and it fails in different ways. What you learn here about words does not explain why a generated hand has six fingers.
Students tend to assume that one mechanism sits behind every AI tool. Say out loud that this panel applies to language models only.
