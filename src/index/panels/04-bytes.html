What an HTTP request and response look like

At a restaurant, the waiter writes your order on a slip that always has the same fields, such as table number, items and notes. The kitchen knows where to look because every slip has the same layout.

An HTTP message is a slip like that, written in plain text. HTTP is the set of rules that browsers and servers use to talk to each other.

A message has a first line, then headers (name and value pairs), then a blank line, and optionally a body, which carries the data. Click any highlighted part to see what it does.

Think first. A browser is a program that writes these text messages for you. Could you write one yourself without a browser? Write down what you would need.

An HTTP message is plain text. These steps send a real one from your own computer. They are also the setup for the exercises covered later in "Group exercises".
