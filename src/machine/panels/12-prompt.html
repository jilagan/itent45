Writing better prompts

If you tell a tricycle driver "somewhere near the market," you could be dropped at any of a dozen places. If you say "the Loyola Heights gate on Katipunan," only one place fits.

A prompt works the same way. A prompt is the text you give a language model, and a constraint is a fact or limit you add to it. Each constraint rules out some of the answers the model might give. A driver can ask what you meant. The model picks one answer from the range that is left, as described in "Predicting the next word".

Think first. Suppose you ask a model for "a function to enroll a student in a course." How many different working answers could that describe? Which one do you expect the model to give you most often, and why?
Let students commit to a guess before they open the widget. Most guess the careful-looking answer that checks the seat count first. Ask them what happens when two students click at the same moment.

Each switch adds one fact the model could not have known. Each fact rules out a group of answers that were otherwise reasonable. The ORM (object-relational mapper) is the part of Django that lets code read and write database rows as Python objects, without typing SQL, the database's own language. System prompts and context A system prompt is text placed ahead of every conversation. It holds the rules that are true every time: the framework you use, your house style, what the model must never do without asking. It is set once and applies to everything.

Context is what applies to one task: the table definitions, the file, an example. Both narrow the range of answers. A system prompt lasts for every conversation and context lasts for one task.
Why the most likely answer is wrong With nothing specified, the most likely answer reads the seat count, checks it, and then creates the row. It looks careful and most tutorials show it. It fails when two students click at the same moment, because both can read the same count before either one writes. This failure is called a race condition. You can see it in the Module 1 site, "Transactions", and later in "Checking AI-written code".

The model gives this answer because it is the most common pattern in the text it learned from, and nothing in your prompt ruled it out.
