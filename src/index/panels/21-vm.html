Virtualization and what the cloud means

A condominium building is one structure that holds many separate units. Each owner has a door, a kitchen and a bathroom, and never sees how the building is divided.

A rented server works the same way. The server with 2 GB of RAM that you rent is one slice of a much larger physical machine. Software creates the slice in seconds, next to slices that belong to other customers. Dividing one machine into slices is called virtualization, and each slice is a virtual machine (VM). The properties we call "the cloud" follow from it.

"Server memory" treated a server as one whole machine with fixed memory, which was a simplification. This panel shows how the slices are made, created, billed and described.

Think first. You rent a server with 2 GB of RAM from a cloud provider. Nobody delivers a computer to you. What do you think you were given?

Bare metal means a physical machine with no virtualization. One operating system controls all of it. The kernel is the core of the operating system, and it controls the hardware. The shell is the program you type commands into. If you buy a bigger machine, you own all of it, including the 80% you are not using at 3 a.m.

Each guest has its own kernel, disk and network card as far as it can tell, but these are simulated. The host is the physical machine, and its hypervisor divides the hardware between the guests. A core is one processing unit. The hypervisor can create or delete a guest in seconds.

Service models: IaaS, PaaS and SaaS

Cooking at home, ordering catering and eating out hand more of the work to someone else each time. Cloud service models do the same for the layers in the table. Every layer is run by someone, and the service model decides which layers you run and which the provider runs. You pay the provider for the layers it runs.

LayerOn-premiseIaaSPaaSSaaS
you run it the provider runs it
Examples. Infrastructure as a service (IaaS) gives you a virtual machine. An Amazon EC2 instance or a DigitalOcean Droplet is IaaS, and you still install the operating system updates yourself. Platform as a service (PaaS) runs everything under your code. Railway and Supabase are PaaS, and you push your code to them. Software as a service (SaaS) is a finished application. Your student portal, Canvas and Gmail are SaaS for the people who use them. Your capstone is a PaaS customer, and it is a SaaS provider to its own users.
