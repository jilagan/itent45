Decision rules and tables

Rules that look clear can clash or leave a case open. A table of every case, plus tests at the edges, finds the gaps before the rules go live.

A campus store's checkout page lists two discounts: students get 10 percent off, and orders over 1,000 pesos get 5 percent off. A student orders 1,200 pesos of books. Should the total show 10, 5 or 15 percent off? The rules do not say. A table that lists every case gives one answer for each.

Think first. Which discount should the 1,200 peso student get? What would you add to the rules so that the page always shows the same total?
Expect answers of 10, 5 and 15. Ask each group to say which rule they used to choose, then move to the table.

A decision table has a row for every combination of conditions. Two conditions make four rows. Students get 10 percent off and orders over 1,000 pesos get 5 percent off. When both apply, the store takes the larger discount. Choose a discount for each row, then press Check.

How many rows

Each new condition doubles the rows. Two conditions make 4 rows, three make 8 and ten make 1,024. A table stays readable for a few conditions, so large rule sets are split into smaller tables.

In software

An if statement, a SQL WHERE clause and a spreadsheet IF formula each write a decision table in a different notation. Reading and changing data with SQL shows WHERE, and HTTP verbs and status codes shows how a service answers a request by applying such rules.

Rules written as sentences can clash or leave a case open. Press an order to see which rules fire on it. Press Flag on an order that has a problem: two discounts compete, or the amount sits exactly on the edge of a rule. Then press Check.

Two rules firing

Two rules can fire on one order without a problem when they change different things. A member order over 1,000 pesos gets 5 percent off and free shipping.

Most rule mistakes sit at an edge. A boundary value for "over 1,000" is 1,000. Test one value below, one at and one above: 999, 1,000 and 1,001 pesos. Write the edge in words, such as "1,000 pesos or more," so everyone reads it the same way.

You can now list every case of a rule in a table, find where rules clash, and test the edges.

Other edges

A birthday on the cutoff date, member number 50 in "the first 50 members," and an empty list are all edges. Test the values on both sides of each one.
