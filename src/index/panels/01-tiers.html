01 — Orientation

A web app is three programs on different machines, passing messages

An agent will write most of this code for you. The shape underneath still earns an afternoon. You have used Django views and SQL queries; what is usually left vague is where each piece runs and what has to happen between them. There are three tiers. Two run on a machine you control. One runs on a stranger's laptop, and that difference decides most of what follows.

Ask the room Point at any part of a page you use daily. Which tier produced it? Most people cannot say, and that is the gap this session closes.

The question worth asking Why not let the browser talk to the database directly and skip the middle? Because the database password would then have to live in code running on the user's laptop. Anyone could read it, and then run any query they liked. The application tier exists to be the only thing holding the keys, and the only thing deciding which questions are allowed.
