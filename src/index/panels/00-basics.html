What is a server?

A sari-sari store is a store only while it is open and someone is behind the counter. With the shutter down, it is a room with shelves. A server works the same way. It is a program that waits for requests from other computers and answers them. Any computer can run one, including the laptop in front of you. The program that sends the requests, such as your web browser, is called the client.

The word means two things
The machine

A physical computer. It has a processor (the chip that runs programs), memory and a network connection. See "How a server's memory is used" for how a server's memory is divided up.

The program

Software that runs on that machine and waits in a loop for someone to connect. Real examples are nginx and gunicorn (two widely used web server programs) and Node.js. This course also uses a twenty-line program, teaching_server.py.

When someone says "the server is down", they usually mean the program has stopped. The machine itself is usually fine.

Who is asking?
An IP address identifies a machine on a network. A port identifies a program on that machine. Think of the IP address as a building and the port as a unit number in it. A delivery needs both.

127.0.0.1, also written localhost, is a special address. It always means this computer, right here, so on every computer it points to that computer itself.
Your laptop has more than one IP address

A laptop has one IP address for each network connection it has, and each address means something different. None of them is the address of your laptop. Data on a network travels in small pieces called packets. Click each address to see how far a packet sent to it travels.

Reading the three addresses

127.0.0.1 is a real address, and nothing sent to it leaves the machine. The packet goes down into the operating system's network code and turns straight back up to another program on the same computer. It still works with the wifi unplugged.

192.168.x.x is a private range. Millions of homes use the same numbers at the same time, so the number alone cannot identify anything on the wider internet. Your router assigns these addresses and keeps track of which device asked for what.

The public address belongs to your router, and everyone in the building shares it. Many private addresses sit behind that one public address, so nothing on the internet can start a conversation with your laptop.
