The context window

A classroom whiteboard has room for a fixed number of lines. When it is full, someone erases the oldest line to make space for a new one. A language model's context window works like that whiteboard. On the whiteboard a person decides what to erase. In the model, the oldest text usually goes first, without any warning.

The context window is the amount of text, counted in tokens (see "Tokens"), that the model can see when it writes a reply. The system prompt, which is the standing instructions an app gives the model, the files you pasted, every turn of the conversation and the reply being written all share the same window. The model only sees what fits.
