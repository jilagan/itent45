Embed codes for the lesson library




With a course chosen, the page that opens from "Open full lesson" shows that course's lesson list. The embedded view itself looks the same.

The snippets and links below use these settings and change as you edit them. The links work after the site is published.

For the instructor. Paste a snippet into the HTML view of a Canvas page. Add a plain link to the full lesson under each frame in case the frame is blocked.

Options on any URL: &cyu=0 hides the questions, &video=0 hides the video, &theme=dark uses the dark theme. &instructor=1 shows instructor notes. The lesson library is at library.html.

Heights for lessons without steps come from the layout audit at 700 px wide. Check them against the live lesson.
