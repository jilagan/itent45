AI agents: the think, act and observe loop

An agent is a language model connected to tools. It thinks, acts and checks the result, then repeats.

Suppose you send an intern to the registrar's office to fix a student's record. The intern decides what to do, does it, looks at what happened, and decides what to do next. A chat model can only produce text. An agent is a model that can also act and see the result.

Think first. Of thinking, acting and looking at the result, which could a model that only produces text never do by itself, and why?
Students usually say the model cannot act. Push for the second half: it also cannot know what happened without a result from outside itself.

Context in use is how much of the model's context window the conversation has filled. The context grows with every step, and the cost per step grows faster than the step count.

Tools an agent typically has

A shell is a window where you type commands. A file system is the folders and files on a computer. A test runner checks whether code still works. Observation lines can also come from an API, which is a way for one program to request something from another.

The name of the pattern

This pattern is called ReAct, short for reason and act. Observation lines are the only lines that can contradict the model.

See The context window for how the window fills.

Four things go wrong in long loops. The model may not stop when the task is done. The context window fills up and pushes out your first instruction. A wrong observation is treated as fact in every later step. Each step costs more than the one before.

You can now name four ways an agent goes wrong and what a person should watch.

More detail

It does not know when to stop

The model stops when it predicts a special end-of-output token, the same way it predicts any other token. That can happen too early, or not at all.

The context window fills

Every thought, action and observation is added to it. After twenty steps your original instruction may no longer be in what the model can see.

Errors compound

A wrong observation at step three is treated as fact in every step after it. The model's confidence does not fade on its own.

Cost grows with each step

You pay per step, the context grows each time, and attention cost rises with the square of the context length. The twentieth step costs more than the first for the same work.
