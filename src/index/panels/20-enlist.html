Enlistment day, and why the cloud did not fix it

A student information system of that era typically ran on a handful of Java application servers with a single relational database behind them. Most such systems have since moved off-premise, so the seven-server limit is gone; capacity at the web tier is now something you can buy in minutes. The database hiccups did not go away. Panel 19 already told you why this would happen.
